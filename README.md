# ポートフォリオ

## Topページ

### introduction
ReactやAstro、Next.jsを使ったモダンなWebアプリケーションの構築に取り組んでいます。デザインにこだわり、ユーザーエクスペリエンスを重視したプロジェクトを作成することが好きです。

### 興味
- WebGL
- アニメーション技術
- 動的なデザイン

### 偉人
- Steve Jobs: イノベーションの精神とデザインへのこだわり
- Tim Berners-Lee: インターネットの発展における先駆者

### できること・してきたこと
- 3Dウェブアプリケーションの開発
- UI/UXデザイン
- React, Next.js, Astroを使ったウェブサイト構築

## Works

### Flipアニメーション
`works` セクションでは、アニメーションを活用して各プロジェクトの詳細を表示します。Flipアニメーションを使って、カードをめくるような効果を与える予定です。詳細ページは必要ないと考えていますが、Flipアニメーションを使用して作品情報を表示します。

### Works詳細
作品の詳細情報を表示します。

## Design

### レイアウト
- `grid`を使用して、効率的にレスポンシブデザインを構築
- `SVGローディングページ`では、円形のアニメーションを使用し、読み込み進行状況を数値で表示

### Enterページ
- `WebGL`の流体エフェクトを使用し、エンターページにインタラクティブなアニメーションを追加
- Raycastingによるインタラクションを実装

## Animation

### アニメーションの選定
- 動的な背景色やフォントカラーの変更
- チェックボックスでフォント変更を行うインタラクション
- `gsap`のFlipアニメーションでスムーズなページ遷移

## SEO設定

SEO対策として、以下のmetaタグを設定します：
- `title`タグ
- `description`タグ
- ソーシャルメディア用のOGPタグ

## MicroCMS統合

- `microCMS`との統合を行い、CMSから動的にコンテンツを取得
- コンテンツはSSRを使って動的にレンダリング

## サーバー設定

- Expressを使用して、動的コンテンツのSSRを設定
- 更新頻度が高い部分（`works`セクションなど）を動的に処理

## Contact Form

コンタクトフォームを実装し、`nodemailer`を使ってメール送信機能を提供します。進捗バーで送信状況を表示する機能も実装予定です。
